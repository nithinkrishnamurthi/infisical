# Add a "Documentation" link to the login page

Add a "Documentation" link to the bottom of the Infisical sign-in page
that opens https://infisical.com/docs in a new tab.

## How to reach the app

Infisical's self-host UI runs on http://localhost. The sign-in page is
the root (/) when unauthenticated.

## Acceptance

- A "Documentation" link is visible on the sign-in page.
- Clicking it opens https://infisical.com/docs in a new tab
  (target=_blank, rel=noopener).
- No existing UI is removed or moved.
